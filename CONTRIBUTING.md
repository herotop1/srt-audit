# Contributing

Thank you for helping! Please open an issue describing the bug or proposal before large changes. For bug reports, share a minimal non-sensitive SRT example, observed result and expected behavior. Fork the repository, create a topic branch, make a focused change, and add tests for behavior changes. Run `python -m unittest discover -s tests -v` before submitting a pull request. Contributions are reviewed on technical merit; no artificial PR activity or download boosting is encouraged.
